How it works

  1. Data: MNIST, 70,000 handwritten digits (28×28 pixels). 60,000 for training, 10,000 for testing.
  2. Model: CNN with 4 Conv layers, 2 MaxPooling layers, Dropout, a Dense layer of 128, and a softmax output of 10 probabilities.
  3. Training: several epochs, batch size 128, Adam optimizer, with rotation, zoom and shift augmentation. 54,000 images train the model and 6,000 validate it.
  4. Testing: 10,000 images the model never saw: see the chips above.
  5. Limits: the model must pick one of the 10 digits. It has no “not a digit” class, so a scribble still gets a guess. The page only blocks marks that are too tiny (like a dot) and shows "Not sure" when the confidence is low.
